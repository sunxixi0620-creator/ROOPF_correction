# 标签重复性有界审查 v1（运行前冻结）

研究对象：此前 long_value_v1 的 576 个状态，不新增函数族泛化主张，不训练网络。原解锁权重及历史结果不变。

按 12 配方和 NFE100/310 分层，每层对状态 ID 作固定角色哈希排序取前两个，共48状态；抽样不读取历史收益。每状态在 Iso/Pop/Center 各4个既有候选中，按另一个角色哈希选一个；几何不合格即不干预，不依据收益替换候选。

每状态使用16个新后续随机流。每个流运行 Base 和三个动作：固定原前缀与当前拟选第一个点，动作只替换当前第二个点，之后恢复同一纯在线策略至600 NFE。在当前候选生成及评分完成之后，同时重置全局候选 RNG 和私有 uniform-slots RNG；同状态同流四个分支使用相同后续随机流。不重采样目标函数，不改变原函数参数。所有操作通过独立研究钩子实现，不修改历史模型源文件。

主指标：初始标准差归一化的有界终局改善差，与同流 Base 配对。流0–7用于从“不干预+三动作”中选平均收益最大项，仅用流8–15评价；交换两半，两个评价收益等权。零并列优先不干预。两项预定主比较为 Crossfit−Base、Crossfit−Random（随机均匀选三动作，弃用动作记0）。每项须平均收益≥0.0001、两个方向均为正、按12配方聚类bootstrap10000次得到的Bonferroni97.5%双侧区间下界>0；两项都通过才称稳定可利用潜力得到支持。0.0001为诊断门槛，不代替历史完整搜索0.005门槛。

描述性指标：两半动作均值相关与符号一致率、条件内方差、单次及16次均值的信号可靠性估计、全部16流事后选优值（标记选择乐观性）、两个阶段完整结果。不得根据它们改变主门槛、抽样或动作。

最多48×16×4=3072条600预算重放，即1,843,200次调用，弃用分支可复用Base；额外契约检查单独计费。每条验证前缀、第一点、替换点、实际预算与无额外目标查询；契约检查无钩子/无重置一致、同种子重现、不同流在两个RNG上的差异。保存源哈希、旧数据哈希、动作和完整轨迹。

如果未通过，不对当前长期价值网络追加特征、epoch或损失搜索；不能由阴性结果推出所有长期价值方法无效。如果通过，仅支持这组状态/动作/后续策略的潜力，不自动训练或声称已有可部署门控。无论结果，新主线以少样本先验价值对照为进入条件。

资源：CPU单线程进程，按可用内存选至多32工作进程；历史同类rollout的CPU吞吐优于GPU，GPU保留给适合批处理的新先验试验。输出完成标记后重启仅核验/读报告，不重复实验。
