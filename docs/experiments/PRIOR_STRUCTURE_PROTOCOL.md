# 可迁移结构与径向偏置诊断 v1（运行前冻结）

分为两个独立证据层次，不重训旧预测器，不修改历史验收条件。

## A. 对已有先验的事后诊断

复用fewshot_prior_v1的保留配方数据与冻结Correct模型，0新增目标调用。比较Correct、打乱当前context的y对应关系（保留全部数值与候选）、固定径向预测、仅用context拟合的径向回归、径向+线性回归、原Online代理。后两者ridge=0.01，截距正则1e-6；径向特征为均方x/5。

记录10/20/40观测下标准化MSE、单次选点效用，以及Correct候选预测方差被常数+候选半径解释的比例。context打乱按任务和观测数固定种子，每个训练种子共享同一打乱。所有结果为历史数据上的事后机制诊断，不宣布新的独立显著性或修改旧门槛，不把预测方差解释率当因果收益贡献率。

## B. 预先定义的共享子空间试验

目的：在具有可识别跨任务结构的受控正对照中，检验离线数据能否提供简单空间中心先验不能替代的信息，同时量化错误迁移。它不是标准基准、新的实际应用，也不能证明原ROOPF、原residual或通用融合必要。

20D立方体[-5,5]^20。12个独立方向组，每组共享一个隐藏的20×3正交矩阵B；组不是12种不同解析函数族。部署含义是假定同一系统的历史任务和新任务共享重要方向，组标识仅用于关联历史数据，不向预测器提供真实B/中心/系数。

每任务生成独立的正交补空间C、移动中心c、三个正系数λ、任务尺度s和偏置b。c在立方体[-3,3]^20均匀采样，最优位置不固定在原点。目标：
f(x)=s*[mean(λ*( (x−c)B )²)+0.2*mean(((x−c)C)²)+0.01*mean((x−c)²)]+b。
C与B正交；λ在[0.5,1.5]，s在[0.8,1.2]，b在[-1,1]。同任务的mismatch条件将输入坐标固定循环置换7位，目标值可通过置换还原核对；源模型仍使用原组数据，目标不获得真实相关性标签。

每方向组三个独立源数据种子，每种子64训练任务×80个均匀点。离线拟合共享二次项与每任务独立线性/截距：在每任务内将二次设计矩阵和y投影到线性+截距的正交补，累计正规方程，加固定1e-5相对对角ridge，闭式求解共同二次矩阵，取最大三个特征向量作为学到的表示。没有epoch或神经网络重训；该闭式正对照用来隔离“结构是否可获得”，不能归为旧神经模型表现。

从仅已观测目标context在线拟合预测器。Learned/Random/Wrong使用同容量的低秩二次特征（截距+3投影+6二次项，共10维）；Random为固定随机正交子空间，Wrong使用下一个方向组的已学表示。RadialLinear使用截距+20线性坐标+平均半径，共22维；OnlineFull使用完整231维二次特征；OnlineRidge使用既有5成员64RFF/ridge0.002代理。除OnlineRidge沿用其配置外，目标ridge=0.01，截距正则1e-6；目标y只按当前context标准化，预测器不访问真实隐变量。

每方向组32个全新目标任务，matched/mismatch配对，context40个均匀点；分别使用前10/20/40观测。每任务两个固定候选池：256个均匀立方体点，以及256个半径4.5的均匀球面点（必在边界内、半径相同，隔离半径排序）。按预测均值选择一点，不使用候选标签。模型冻结后才产生目标数据；全部候选标签只用于离线诊断，计入数据采集成本。

主比较限matched：Learned相对Random/Wrong/RadialLinear/OnlineFull/OnlineRidge，分别在box/shell报告MSE相对降低和候选归一化选择遗憾降低。遗憾=(选点值−候选池最小值)/context目标标准差，非真实全局regret。先在每组内平均MSE再求相对降低。三个context数等权，三个源数据种子等权，12独立方向组聚类bootstrap10000次。20项比较Bonferroni99.75%双侧区间。MSE降低门槛5%；选择遗憾绝对降低门槛0.01；均要求区间下界>0、三个源种子效应均正。20项同时通过才称该受控结构的独特信息门槛通过。

mismatch全部对照、主方向夹角/投影误差和逐context结果完整报告，属于预定诊断，不替换matched主验收，不据此改训练量/秩/正则。若失配退化，应明确需要独立的失配适应验证，不能声称先验普遍可靠。若部分门槛未通过，保留具体正面结果而不扩大为全面成功。

预算：源训练12×3×64×80=184320；目标12×32×2×(40+256+256)=423936；合计608256次。无早停验证集、无按目标集调参。独立契约另计。测试时查询的所有候选标签是诊断费用，不能算成只有11/21/41次的部署结果。保存输入、标签、源表示、划分、全部预测及源哈希。

资源：源表示拟合和分组评测可并行至多32个单线程CPU进程；GPU用于旧冻结网络批量诊断。原解锁checkpoint保持。此轮仅完成结构与失配诊断，不自动开展弱离线对照来制造A/O/F必胜结果；下一轮完整融合方法须由这次结构证据单独定义并冻结。
