# 共享结构失配下的因果选择与闭环验证 v1（运行前冻结）

前置：shared_structure_v1的20项matched门槛通过且源表示/全部预测独立复核。使用同一冻结表示，不追加训练、改秩或改正则。目标任务角色全新。此阶段是受控机制实验，不是原ROOPF，不宣称真实应用或新颖性。

T=冻结的源数据表示+目标任务在线二次回归；O=只在目标数据上拟合完整二次回归；S=根据当前archive留一预测误差，在T/O中选择误差较小的模型（并列选O）。T也含在线系数拟合，因此不是原意义的纯离线anchor。比较T/O/S回答源表示和全空间适应是否互补，不能替代原A/O/F/FR。

回归：x/5，特征去除截距后在当前context中心化，目标y中心化，ridge=0.01，截距不正则。通过线性模型hat矩阵精确计算留一误差，不进行额外目标查询、不读取真实共享方向或matched标签。S为整轮选择一个预测器，不调权重。另设Fixed（T/O均值0.5）、RadialS（径向+线性与O做同样选择）、WrongS（错误方向组表示与O做同样选择）。

任务：12方向组×4新任务×matched/mismatch两条件=96个任务；三源数据种子。matched与mismatch各50%是预定机制测试分布，不声称实际应用有此比例。T/S/Fixed/WrongS各96×3轨迹；O/RadialS各96条共享；总1344轨迹，每条300NFE，共403200次目标调用。20点共同初始化；每轮1点，候选64全域均匀+64围绕已观测最优的局部高斯，标准差10×(0.05+0.35×剩余比例)，裁剪边界、排除已观测重复点。随机角色在方法之间匹配；状态分化后只保证生成规则相同，不保证局部点相同。

主终点300NFE有界标准化改善，与历史定义相同。主要四比较S−T、S−O、S−RadialS、S−WrongS在预设50/50分布上平均；每项需均值≥0.005、99%区间下界>0、三个源种子效应均正。第五主约束为mismatch下S相对O非劣：99%区间下界>−0.005，三个种子均值≥−0.005。五项Bonferroni控制；按12方向组聚类bootstrap10000次。全部通过才进入新的外部任务设计。S−Fixed为次要95%/0.001门槛，不替代主条件。

matched/mismatch分别、20/40/100/200/300曲线、选择T比例、两预测器留一误差全部保存。曲线与源任务比例不事后重定义主终点。错误源的退化不能隐去。输出解释限于已知二次/秩3正对照；原神经先验和原residual未参加。

契约：精确LOO公式与逐点删除后重拟合比较；强制S选择T/O时分别复现T/O轨迹；相同初始化；每轨迹恰好300调用；源权重不变。额外契约4×24=96次，代数LOO检查0目标调用。所有模型选择只用过去付费观测。

若任一主门槛失败，停止此选择规则的阈值/正则/预算搜索，报告哪些证据成立。若通过也只支持受控分布，先设计真实相关任务与更强外部优化器对照，再决定论文定位；不把结果归给原方法。
