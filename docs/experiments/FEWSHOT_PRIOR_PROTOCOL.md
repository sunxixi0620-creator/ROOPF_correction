# 少样本先验价值原型 v1（运行前冻结）

目的：检验离线源任务是否能改善10/20/40个观测下的预测和单次选点。不是完整搜索，不是原ROOPF/residual验证，不使用分支终局标签。使用现有程序生成族的新实例，按配方分组，明确属于开发机制试验；不宣称新的独立函数族。

20D，12配方×3尺度。三个外层fold，每fold保留recipe%3==fold的4配方作测试，其余8配方中最后2个作早停验证、前6个训练。每训练配置32个实例（576任务/fold），验证每配置16个实例（96任务），测试每配置16个实例（192任务）。角色与fold进入实例种子。每任务均匀采样40个context点，训练64个query，验证/测试256个query。任务参数、身份、解析参数不作为模型输入。输入仅坐标和context中已经观测的y，按context自身均值/标准差归一化。

模型为条件点预测器：每对query/context拼接坐标、差值、观测标准化y和均方距离（62维），MLP62→64→32；可学习attention修正与固定距离权重组合，聚合观测y；MLP52→64→1根据聚合pair表征和query坐标提供预测修正。两个输出头零初始化，初始预测退化为固定距离加权均值。模型输出点预测，不声称概率校准/不确定性保证。

三初始化种子，各训练Correct和Shuffled。Shuffled在每个源任务104个点之间固定打乱y，不改变坐标、模型容量和标签边际分布；破坏输入输出关系，作为负对照。Untrained为同种子初始网络；Online为当前纯在线策略的五成员RFF ridge代理（相同20D/64RFF/0.002），仅拟合当前context，不用离线数据。全部方法候选池相同，均按预测均值选一个最低点；不混入不同的采集策略或额外目标查询。

Adam lr0.001，weight_decay0.0001，batch64，最多120epoch；每个batch的context数按固定种子从10/20/40选一个。每5epoch在相同正确验证任务上按三个context数平均标准化MSE选模，连续4次未改善早停，允许选中0epoch。Correct/Shuffled均遵守同规则。三个fold共18个训练模型；全部checkpoint先冻结再打开测试标签。不得依据测试调整模型、输入、epoch或阈值。

主结果为三个context数等权、三个训练种子等权，再按任务配方聚合的六项比较：Correct相对Untrained/Shuffled/Online各自的预测MSE降低和单点效用改善。MSE相对降低=(对照MSE−CorrectMSE)/max(对照MSE,1e-8)，先在每配方内平均MSE再求相对降低；门槛平均≥5%。效用为选中一个点相对context最优的有界标准化改善g/(1+g)，差值门槛≥0.001。六项用12配方聚类bootstrap10000次、Bonferroni99.1667%双侧区间，均要求下界>0且三个模型种子平均效应为正。六项全部通过才进入融合开发。逐context数、所有种子和全部函数保留，不事后挑选条件。门槛属于这一预测/单次决策原型，不能代替历史0.005完整搜索标准。

没有完整搜索终局对照；即便通过，也不能声称F>A/O。若不通过，停止此原型结构/epoch搜索，报告是预测未成立、选点收益未成立还是未超过强在线对照；不能推出所有先验方法无效。原解锁版及旧负结果保持。

离线调用预算：每fold训练576×104，验证96×296，测试192×296，共145152，三个fold435456次；另计预检。测试query标签仅用于冻结模型后的评测及诊断，必须报告这部分数据采集成本，不能包装成每任务只调用11/21/41次的完整运行。训练/推断不再调用目标函数。保存全部输入、标签、划分、预测、checkpoint、源哈希。

在纯合成张量上对同等训练步数计时CPU/CUDA，按速度选择设备，不用科学结果选设备。CPU为1线程；GPU可用时逐模型大batch训练，避免18进程争用一张卡。源任务采集顺序运行，与CPU分支审查并行，不再额外开启大批rollout进程。
