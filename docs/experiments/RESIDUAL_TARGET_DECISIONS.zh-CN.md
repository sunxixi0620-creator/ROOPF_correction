# Residual目标对照：解释与决策

本轮完成了用户指定的训练专用数据采集、两个目标的训练与验证早停，以及冻结选模后的完整优化确认评测。最终解锁版及其anchor/residual权重未替换。

## 能得到的结论

1. **训练轮数必须跟随验证表现。** 相同网络、训练实例、超参数和两个初始化种子下，incumbent目标在第2/4轮选中最佳模型，10/12轮触发早停；second-anchor目标在第14/18轮选中最佳模型，22/26轮早停。这些是当前数据与学习率下的结果，不是通用最佳轮数。两个目标的BCE是不同任务，不能直接比较其数值大小。
2. **目标对齐可改善对应的预测任务，但增益不能直接外推。** 后期确认候选中，second-anchor目标的Brier为0.0606/0.0605，优于相应训练先验常数基线0.1591。原模型的概率预测针对incumbent目标，对second-anchor标签的Brier0.4494只说明不能把其输出当作该事件的概率，不是原模型在其本来任务上的公平排名。
3. **预测改善未转化为明确的完整优化优势。** 新second模型完整优化得分0.243830/0.243662，原最终模型0.243355。绝对差仅0.000475/0.000307；36个条件均值WTL为18/4/14、18/3/15。结果方向值得研究，但还不足以声称稳定优于最终版。
4. **更好的incumbent概率也不保证更好的优化。** incumbent模型在对应任务的后期Brier由原模型0.1122下降到0.0665/0.0663，但完整优化得分降至0.242949/0.242218。须区分标签拟合、候选排序、门控决策及最终搜索效果。
5. **标签可能过于容易，无法提供足够排序信息。** portfolio候选击败第二anchor的正例率为84.57%；原模型与新second模型的top5精度均约99.9%。新标签对概率语义更合适，却未明显改善top5区分力。新second模型相对无residual在23/24个条件均值完全持平，这不证明轨迹或每次决策相同，也不能单凭最终值确认其原因。

## 后续应优先验证什么

保留本轮模型为开发候选，原始最终模型保持冻结。下一步优先记录“加入residual前后实际改变了哪些决策”，在固定状态下统计改变率、被选候选相对第二anchor的真实改善幅度，以及这些干预是否改善最终结果。若主要瓶颈是高正例率带来的排序饱和，再在新的训练数据上比较池内排序或改善幅度目标；不要仅靠增加训练轮数或根据本轮确认结果调门控阈值。

用于新目标/规则开发后，应重新准备确认实例，并在配置冻结后验证外部任务与强基线。当前结果不构成论文预期效果已实现、全新函数族泛化或统计显著领先的证据。

## 范围和复现限制

训练72个实例、验证36个实例、确认36个实例，每实例4条轨迹，都是已知36函数族。两种目标各两个训练种子。新数据包含两个anchor行，历史残差数据没有这些真值；因此只在两个新训练目标之间具有相同数据的受控比较，原模型与新模型之间还有数据分布和训练方案差别。

确认标签由无residual策略生成，完整优化确认独立运行六种方法，不向优化器提供教师真值。196个正式输出文件归档并校验，原始权重哈希不变。实现预检阶段的部分旧种子数据已隔离，未参与任何训练或报告中的正式预算；未完成的预检任务不计入精确总算力声明。
