# Cold-start development protocol v1

Frozen before new outcomes. Scope: 20D procedural tasks, 36 configurations (12 recipes x3 scales), two new instances/configuration, three existing trained-prior seeds. All families have historical development exposure; no claim of independent confirmation. No external tests unsealed. Reuse held-out-recipe fold checkpoints from fewshot_prior_v1 (trained with 10/20/40 contexts); 5-context diagnostic is extrapolation. No neural training, no old residual, no original checkpoint changes.

Shared 10 uniform initial points per task/instance, count every objective call. Prior frozen on these 10 observations; mean/population-std normalization fixed with floor1e-6. Methods: O full-archive online GP; P frozen prior mean minimization; F prior + GP residual/EI throughout; W same F until exactly40 paid evaluations, then remove prior and refit GP to ALL observed standardized raw values; S 30 scrambled Sobol points after initial10, then same O. GP in F/W also uses all10 context observations; its variance is conditional on a data-derived fixed mean and does not represent all prior uncertainty. Kernel Matern5/2, length sqrt20*.25 on box-normalized coordinates, nugget1e-4, full archive, no hyperparameter tuning. Reuse frozen correction GP math. Update GP targets exactly when prior removed. O/S no neural seed and shared without counting replication as independence.

Candidate rule 64 global uniform +64 local Gaussian around observed incumbent, local std10*(.05+.35*(600-n)/600), box clipping and exclude paid duplicates within1e-6. Same role/task/instance/step random stream; state-dependent coordinates can diverge. P mean minimum, others EI xi0. No objective truths consulted in ranking. One trajectory to600, primary prefix300 (not an independently run300-budget policy).

72 tasks x (3 seeds x P/F/W + O/S)=792 trajectories,475200 objective calls. Two instance roles are held out from earlier runs; model folds selected by recipe solely in evaluation orchestration. Fixed early target y_best10 - 0.5*sample_std(y_initial10), no outcome-selected thresholds. Secondary targets .25 and1.0 standard deviations. Time starts with total paid evaluations; not reached by300 is censored and represented as restricted time301, never dropped or called a success. Report success rate and restricted mean time, plus curves and bounded utility u=g/(1+g) with g=max(best10-best_t,0)/sample_std(initial10), floor1e-8. Difficulty determined by this rule; if too easy/hard, disclose and do not change target in this run.

Primary W vs O AND S: restricted mean time saved >=5 evaluations, simultaneous97.5% percentile recipe-cluster bootstrap lower>0, each model-seed mean positive. W terminal600 utility minus each control lower97.5% >-.005 (noninferiority margin). Joint pass requires all efficiency and noninferiority criteria, plus attainment at300 not lower on average. Aggregate2instances/3scales/3modelseeds within12 recipe clusters;10000 resamples seed202609301. These are development intervals, not unseen-family inference. W-P/F comparisons descriptive; don't claim online/exit necessity without separate confirmation. Curves and AUC are secondary and cannot rescue gate failure. No selecting best budget, seed, context, switch time or kernel after results.

Diagnostic first:36 separate instances,40 uniform context +128 independent uniform queries (6048 calls). Evaluate n5/10/20/40, correct prior/P, shuffled prior, O and F for all3seeds on common queries. Record standardizedMSE, true-best-decile recall among predicted-best13, selected query's normalized true regret and probability it improves contextbest. Diagnostic truths never enter main training/selection. No selection based on diagnostics; full bounded study runs once regardless, to test whether prediction gains transfer.

Before runs: incremental/dense GP checks; W removal all-history target identity; W zero prior vs O same trajectories; W vs F first40 identical, W no learned prior calls after switch. End-to-end contracts O/Wzero/F/W, budget45 each=180 calls. Total new calls481428=475200+6048+180, no neural epochs. Replays make0 objective calls. Hash source/checkpoints/protocol before runs. Verify budgets, uniqueness, common initialization, frozen priors, sampled decisions and switch-state reconstruction. Use24 CPU processes,1 numerical thread each. Stop if joint gate fails; do not launch adaptive exit/shuffled closed-loop or train more. If pass, report feasibility only and design next-stage exit controls before implementation.
