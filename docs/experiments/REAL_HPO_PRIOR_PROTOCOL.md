# Real-data HPO prior pilot v1 — frozen before objective evaluation

Purpose: test a new sample-efficiency hypothesis on actual model-training objectives. This is a bounded development pilot, not independent confirmation of the original ROOPF or a replacement for its residual ablation. No modification of original checkpoints. No post-result parameter/budget sweeps.

Data: sklearn 1.7.2 bundled digits, 1797 images, 64 pixel features divided by 16. Sources: https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html and https://scikit-learn.org/stable/modules/generated/sklearn.svm.SVC.html . Save exact local data and hashes. Classification task = unordered pair of digit classes. Split the 45 pairs by a fixed role-specific random permutation into 30 source and 15 target pairs. Separately split each class's image indices 50/50 into source and target pools, so no image used for source training/validation occurs in any target training/validation. Classes and acquisition domain remain shared; pairs share images within each pool, so this is not 15 independent datasets, writer-disjoint transfer, or broad generalization.

Each source pair has two fixed stratified 60/40 train/validation splits; each target pair has three. Optimize validation balanced error of RBF SVC(C,gamma), class_weight=balanced, tol=.001, max_iter=-1. 16x16 fixed grid: log10(C) in [-3,3], log10(gamma) in [-5,1]; probability=False. All 256 settings evaluated for each task, solely to construct a reproducible finite benchmark. Source = 60 tables / 15360 fits; target = 45 tables / 11520 fits. Report all 26880 fits and runtime, not just simulated online budget. No separate classification test-set claim.

Offline prior p(x) = equal-task mean source validation error, using source tables only. No neural training or epochs. Negative prior = same values under a fixed permutation of configuration indices; this is a falsification control, not realistic task shift. Prior computed and hashed before target evaluations; objective table hashes and method source frozen. Original anchor/residual excluded.

Seven policies: A ranks frozen p and ignores observed values after common initialization (pure offline policy); O is target-only ordinary-kriging EI; F uses the same online model plus source mean alpha*p; Fixed uses alpha=1; Bad uses permuted p with the same F rule; Random uses random unseen configurations; GP uses sklearn optimized Matern GP-EI as an additional online reference. A and Fixed differ: Fixed also adapts online. F selects alpha from [0,.25,.5,1] by exact leave-one-out MSE on paid observations only; ties choose lower alpha. This finite online rule is frozen, not a posthoc search of validation targets.

O/F/Fixed/Bad: Matern 5/2 kernel, amplitude .25^2, isotropic lengthscale .25 on normalized grid, diagonal noise variance .0001, unknown constant offset fitted by GLS. Exact universal-kriging LOO residual (P(y-alpha*p))_i/P_ii, P=Kinv-Kinv11'Kinv/(1'Kinv1). Predictions use GLS intercept and conditional GP residual; variance includes intercept uncertainty. Minimize by EI, xi=0; no new labels for ranking or LOO. GP: ConstantKernel(1,[.01,100])*Matern([.25,.25],[.05,2],nu=2.5), alpha=1e-4, normalize_y=True, optimizer=fmin_l_bfgs_b, zero restarts, refit at each decision. Count convergence warnings, retain results. Candidate set identical to all policies; exclude evaluated indices, lexicographic ties. Kernel learned online only for GP; no claim fixed-kernel O is the strongest available optimizer.

Each target table x three initialization seeds, same four unique random initial configurations for all policies; total 32 unique evaluations including initialization. 45*3*7=945 trajectories / 30240 table lookups (not new SVC fits). All continue to 32 regardless of success. Choice API receives only indices and observed labels, never entire target table. Archive all selections, errors, alpha/LOO and decision runtime.

Evaluation only, after all traces exist: normalized simple regret r_t=(best_t-table_min)/max(table_max-table_min,1e-12). Primary sample-efficiency score is mean r_t over t=4..32 (lower better). Target quality is r<=.05; hitting time starts at evaluation 1, failures coded 33; report success rate and capped mean time, not uncensored expected runtime. No use of min/max/target in policy decisions. Also report absolute balanced error and full curves to reveal ceiling effects.

Six joint pilot entry conditions: AUC improvement (control-F) over A, O, GP and Bad >=.005, and capped time improvement over A and O >=1 evaluation. Each requires adjusted bootstrap lower bound >0 and positive mean effect for each of three initialization seeds. Bootstrap 15 pair clusters, aggregate split/init within cluster, 10000 resamples, Bonferroni two-sided confidence 99.1666667% for six tests. Correlations across pairs sharing images mean these intervals are descriptive pilot uncertainty, not an independent-dataset significance guarantee. Fixed and Random comparisons secondary. If any condition fails, stop this prototype; do not broaden into expensive benchmark claims, tune the grid, or replace the endpoint. Passing only warrants a separately designed multi-dataset study and does not validate original ROOPF or residual.

Contracts before target access: exact LOO versus explicit leave-one-out refit; F forced alpha=0 equals O and forced alpha=1 equals Fixed; poisoned unobserved table labels cannot alter choices; source/target image and pair disjointness; common initialization, uniqueness, exact budgets. Verification replays all selections using only paid histories, checks hashes and recomputes all reports. No SVC re-evaluation in replay. Use up to 24 CPU workers with one BLAS thread each; no GPU benefit for libsvm, and no unrelated processes modified.
