# 冻结先验的闭环融合 v1（运行前冻结）

前提：fewshot_prior_v1 六项先验价值门槛通过且独立复核。新方法原型，不是原解锁模型，不是旧residual改名。只使用已冻结的三个fold×三个seed的Correct/Shuffled模型，不再训练。

20D/300NFE，20点共同均匀初始化，每轮1次目标评估，共280次顺序决策。每个目标配方只使用将其留出的fold模型。12配方×3尺度×2新实例×2初始种群=144任务/初始化。三个训练种子；固定任务角色prior_fusion_v1，与源训练/验证/少样本测试均不同，但仍是开发配方的新实例。

每轮候选池为64个全域均匀点＋64个以已观测最优为中心的高斯局部点，标准差=10×(0.05+0.35×剩余预算比例)，裁剪边界。随机流由任务、种群和步数确定，方法之间相同；不同方法状态导致局部点不同，这是共同生成规则，不声称全程候选坐标完全相同。排除与archive数值重复的点。所有方法按预测均值最小选一个，不引入不同采集函数。

离线预测器权重冻结；每步从全部已观测点用预定无标签随机子集取至多40点作context，输出目标尺度预测。它会通过context前向推断适应任务，因此A不是“完全不读取在线观测”。在线代理沿用五成员64RFF/ridge0.002，对全部archive（最多299点）拟合。没有100点warm-up。

方法：A仅冻结Correct先验；O仅在线代理；F两预测加权；Fixed为两者固定0.5；Fshuffled将F的离线模型换成同seed的Shuffled；Fanalytic将F的离线预测换成无预训练的径向解析先验。解析预测为context目标均值＋目标标准差×(query均方归一化半径−context半径均值)/context半径标准差，后者下限0.01；作为中心偏置控制，不读取函数身份/最优点。

F/Fshuffled/Fanalytic权重由因果的已观测预测误差更新：两个误差初值1，先验权重w=(err_online+0.05)/(err_prior+err_online+0.10)。选点前保存两个预测，获得该点唯一目标值后更新err←0.9err+0.1×((预测−真值)/初始化目标标准差)^2。所有评分/门控仅使用已付费观测，没有候选真值查询。该加权是经验规则；选点分布有偏，误差不能当成全域校准保证。

主终点为300NFE相对共同初始化最优的有界归一化改善。四项主比较F−A、F−O、F−Fshuffled、F−Fanalytic：均值≥0.005、Bonferroni98.75%区间下界>0、三个种子均值>0；四项全部通过才进入外部确认。F−Fixed单独作为次要机制诊断，名义95%区间，门槛0.001，不能代替主门槛。记录40/100/200/300曲线，不能事后换主终点。按12配方聚类bootstrap10000次。

A/F/Fixed/Fshuffled各144×3轨迹，O/Fanalytic各144条并在训练种子间共享，不重复计算为独立样本。合计2016条轨迹、604800次目标调用；独立契约另计。在线拟合、先验预测与采集评分0额外目标查询。报告训练成本另见父研究，计时包含当前实现实际必需计算，不将相同O复制计费。

第四原residual组仍保留在历史实验；本轮没有可与新预测器匹配的原residual目标，不强行启用。Fixed/Fshuffled/Fanalytic各有明确控制目的，不称FR。先证明A/O/F，再决定是否需要另一个独立校正组件。

若任一主比较未通过，停止此融合原型，不自动扫权重、改context/候选池或补训，保留先验预测正面证据与闭环结果差异。全部通过也只支持开发族内闭环结果，不能声称完全独立泛化或原三模块必要。原解锁权重保持。
