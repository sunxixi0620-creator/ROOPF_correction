# 训练充分性：本轮结论与后续决策

本轮完成了同一复现训练状态从80轮到160轮的两组配对续训。原始最终10-D anchor与residual权重没有替换，哈希校验通过。这里评估的是anchor单独优化表现，不能等同于更换anchor后的完整ROOPF表现。

## 80轮是否足够

不能仅凭轮数判断。沿用原目标时，预设验证检查点中80轮得分最高（0.027926），160轮为0.023656；因此本轮不支持单纯延长原目标训练。以初始种群标准差统一衡量候选真实改善的shared_scale目标，在160轮取得本轮最高验证分0.067479，曲线尾部仍上升，尚不能声称收敛或160轮最佳。

冻结选模后，在另一组生成参数与初始化种子的确认集上，80轮起点得分0.026887，shared_scale选中模型得分0.067085；72个函数×实例条件的均值胜/平/负为43/23/6。这支持在该复现起点上进一步研究训练目标，而不是承诺增加训练必然改善论文成绩。得分是归一化改善的有界变换，不是成功率。

原始最终anchor在同一确认集得分0.098064。shared_scale相对它为21胜、10平、41负（288轨迹为67/105/116），不能替换最终模型。原始最终模型的精确历史训练随机状态仍未恢复，不能从复现续训的表现反推原模型当年的最佳轮数。

## 其他模块

- Residual：历史3,240,000行候选日志缺少anchor真值，不能可靠地直接重标。本轮新采集的后期池候选中，“改善历史最优”和“击败实际被替换的第二个anchor”标签分歧72.72%。这不是门控错误率，也不是训练新标签必然有用的证据。第二anchor标签正例率约83.21%，后续必须防止只学到多数类。此前日志的早期最佳验证分也不支持盲目追加epoch。
- 未训练的神经gate：保留成功记忆、移除随机logits，相对完整配置为35/20/17；均匀权重控制为43/4/25。随机gate没有显示一致必要性。对照未移除或训练其他辅助网络，不能据此评价所有未训练模块。
- 在线代理：当前使用解析求解的ridge拟合，不存在对应的神经网络训练epoch；应检验排序质量、正则化与计算开销。

## 下一轮的研究顺序

1. 保留最终模型与当前证据快照。先在开发任务上做多个训练种子的从头训练，比较原目标与shared_scale；固定训练日程、检查点与验证选模规则，再决定是否延长到160轮以后。不要根据已看过的外部基准成绩选轮数。
2. 从训练专用实例重采包含两个anchor真值的residual数据，保存实际替换对象和特征；本轮验证/确认诊断数据不能转作训练集。比较现有标签、实际替换标签与排序目标，使用验证早停，并报告类别比例、校准和实际门控决策收益。
3. 先检验简化gate是否稳定，再决定是否为gate引入训练；避免仅因它有网络结构就增加训练成本。对其他固定初始化网络分别做受控消融。
4. 候选配置冻结后，评估完整ROOPF相对同一anchor和强基线的表现，并使用未参与本轮开发的新评测任务。现在还不能声称已达到论文预期效果。

本轮只有一个续训随机流；验证与确认均是已知36函数族的新实例，并非完全未见函数族。7,200次正式轨迹执行包含重复验证和共享对照，不是7,200个独立样本。完整性检查覆盖427个归档文件、权重对应关系、数据和协议哈希、求值预算及配对标签，全部通过。
