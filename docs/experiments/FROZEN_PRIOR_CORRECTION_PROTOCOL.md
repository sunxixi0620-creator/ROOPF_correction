# Frozen prior + online GP correction v1 (pre-run protocol)

Scope: original 20D procedural continuous optimization distribution, 600 real evaluations. New method candidate, not original unlocked ROOPF, not the old offline residual selector. No neural retraining, checkpoint overwrite, extra application benchmark or new residual training. Reuse all nine correct and nine shuffled fewshot_prior_v1 checkpoints, selecting each fold only on its held-out recipes. Fold selection is evaluation orchestration, not a task-identity input to an optimizer. Existing families are development evidence despite new instance roles.

36 configurations (12 recipes x3 scales), one new instance and one common initialization per configuration, three frozen model seeds. This is a bounded mechanism experiment; one instance per configuration does not establish instance-general robustness. Initialization100 uniform points in[-5,5]^20; first40 points are fixed context C for all prior predictions and fixed y centering/scaling (population std floor1e-6). Context choice is index-based, not label-selected. Correct/shuffled model m0(x|C) never changes during a rollout. Remaining60 initialization observations and subsequent500 observations fit GP corrections. Context points are excluded from correction fitting. All methods see/count the same100 initialization values for best-so-far, candidate generation and normalization. Thus P reads initial observations but fits no target model; it is not the old anchor.

Kernel: unit-amplitude Matern5/2 on x mapped to[0,1]^20, isotropic lengthscale sqrt(20)*.25; diagonal regularization1e-4. Fixed hyperparameters, no optimization or parameter sweep. Zero-mean residual GP, data y standardized with C statistics; residual target is y_standardized-m0_standardized. Full exact GP with all eligible observations, no archive cap. Incremental Cholesky must match dense recomputation; double precision GP, existing float32 task/prior preserved. This nugget is numerical/model regularization, not a claim of noisy objective observations. O100 uses all paid points, O60 excludes C; both use exactly the same kernel/EI and no checkpoint. Fixed-kernel O100 is a matched reference, not a claim to be the strongest GP implementation.

Eight groups:
- P: correct frozen conditional prior, mean minimization, no correction.
- O100: GP of raw standardized values on all100+ observations, EI.
- O60: same online GP on60+ observations, EI (structural control).
- F: correct m0 + GP of residuals, EI.
- Mean: same corrected posterior mean as F, mean minimization.
- Shuffled: F with matched shuffled-training checkpoint.
- Blend: .5*m0 + .5*O60 posterior mean, .5*O60 posterior std, EI. The prior is treated as deterministic in this comparator; this is a new matched fixed blend, not a rerun of the old dynamically weighted Ridge method.
- Analytic: same correction/EI using fixed context-normalized radial predictor (qx/5 squared mean minus context radius mean, divided by context radius std floored .01), no learned checkpoint.

P/F/Mean/Shuffled/Blend run36*3 each; O100/O60/Analytic run36 each and are shared without duplicating cost or independence. Total648 trajectories,388800 objective calls. No FR group is claimed; old residual remains excluded until this new fusion is supported and a separately defined matching residual objective exists.

Common candidate rule:64global uniform +64Gaussian local points centered at paid incumbent, std=10*(.05+.35*remaining_budget_fraction), clipped[-5,5], unique relative to all paid archive (distance>1e-6). Common task/step RNG, but state-dependent local coordinates diverge across methods; do not call full trajectories identical candidate pools. All rank the full128 candidates, one real evaluation per step, no teacher lookups. Minimize by standard EI with xi0 against the common observed incumbent; P/Mean use posterior mean. No alpha tuning, new gates or forced anchor slots.

Primary endpoint600NFE: bounded improvement u=g/(1+g), g=max(initial100_best-final_best,0)/std(initial100). Four primary contrasts F-P/O100/Shuffled/Analytic require mean>=.005,98.75% cluster-bootstrap lower>0, all3model-seed means>0. Aggregate scales within12 recipe clusters,10000 resamples. Joint gate must pass before any external confirmation or residual experiment. Secondary F-O60/Mean/Blend require mean>=.001,98.3333% lower>0, all3seeds positive, reported separately. Failure of an exploration/correction secondary contrast means that component is not established even if primary gate passes. No posthoc endpoint changes. Record100/200/300/400/600 curves and uniform100..600 mean utility as descriptive outputs; they cannot rescue failed600NFE gate.

Before closed loop, independent fixed-context predictive diagnostic:36 separate task instances,100initial+128uniform diagnostic queries each=8208 calls. Reuse query truths only for reporting predictions, not search/training. Compare initial P/F/O100/O60/Shuffled/Blend/Analytic on the same coordinates; save MSE and95%interval coverage (predictive variance=GP latent variance+regularization; Blend includes scaled GP variance). This is a diagnostic, not a performance gate or a tuned validation set. No changes based on those metrics. During search log selected-point prequential error/coverage; selection bias means these are not global calibration guarantees. Offline-prior uncertainty is not modeled; reporting GP variance does not assert calibrated total uncertainty.

Pre-run algebra: incremental/dense GP agreement, append variance finite, prior unchanged on fixed queries after GP update. End-to-end contracts use independent roles:O60 vs F with forced-zero prior; P vs Mean with correction disabled;4*104=416 objective calls. Duplicate evaluation and hidden teacher access prohibited. Exact ledger:388800+8208+416=397424 real calls. Any extra debugging/repeat calls must be separately counted, not concealed. Contract failures halt before scientific runs; no performance-based protocol adjustments.

Verification: source/checkpoint hashes, every trajectory600calls/no diagnostic calls, same initialization, immutable context, frozen model fingerprints, all observed/trail metrics; reconstruct sampled early/middle/late decisions from saved paid histories, including posterior/EI and candidate generation. Replay uses saved target labels and makes0new objective calls. Independent summaries and paired statistics recomputed. CPU up to24single-thread processes for exact GP; do not occupy GPU merely for utilization. Any performance smoke is a designated final case retained in the full study, not a discarded tuning run.

Stop: if primary gate fails, retain negative results and stop this candidate; no lengthscale/nugget/context/epoch sweep, no unsealing external tests. Original checkpoints remain unchanged.
