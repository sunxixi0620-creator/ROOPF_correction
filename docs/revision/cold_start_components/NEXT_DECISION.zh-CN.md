# 七组组件结果后的决策

## 核心发现

此前已经重复的W相对O/S冷启动速度收益再次出现。但本轮加入的解析径向先验WA平均达到时间83.829，与学习先验W的85.906接近，W相对WA的节省为−2.077次，调整区间[-6.311,+1.779]跨零。不能说WA在总体上显著更优；也没有证据说神经学习先验优于这个低成本结构先验。

W相对打乱先验WS节省14.049次，说明正确训练关系有信息，不是任意网络都一样。然而胜过打乱关系并不充分证明学习必要，因为一个无训练解析先验也能获得接近的效率。当前瓶颈是学习知识相对简单结构先验的增量价值，而不是是否存在先验辅助收益。

W相对纯先验P的终局有界效用增加0.029870、调整区间[0.017689,0.043389]，在线适应贡献通过预设验收。W相对持续融合F没有速度优势（−0.276次，区间跨零）；虽终局略好0.002413，但低于0.005实质增益量级，不能将退出机制称为已证明必要。固定退出仍可保留为简单规则，不声称40次最优。

W相对O的严格保护条件在本轮通过，但相对S未通过：达到率84.105%低于S的85.185%，差1.080个百分点。W相对WS/WA的达到率也较低。所有较快均值都必须与这些覆盖率结果一起报告。

## 论文目前可以写什么

可以支持：在所研究的任务分布中，合理的初始函数先验有助于冷启动；结合在线适应比只依赖冻结先验更有效。需要限制：当前学习先验没有证明优于简单解析先验，固定退出没有证明必要，预算内覆盖率保护未全面通过。不能写离线学习和所有组件已被证明缺一不可，也不能追溯归给原anchor/residual。

解析先验只根据坐标平方半径相对上下文半径的标准化值给预测，不需要神经训练；它的表现提示当前任务分布可能允许简单形状偏好解释相当一部分收益。这是解释假设，不是已证实的全部因果机制；本轮也没有证明两种先验数学等价。

## 下一步的边界

暂停以当前网络为核心的性能扩展和继续调窗口/训练轮次。把WA固定为必需强对照，不能今后只保留O和WS。若坚持离线学习作为主要创新，下一项研究必须先说明准备迁移的具体结构，以及这种结构为什么不能被当前解析先验替代；并结合已有结构迁移实验，避免重复已经失败的路线。新的训练分布/模型是方法重设计，需要新协议与未用于选择的任务，不能通过挑掉WA表现好的函数来创造优势。

如果保留当前方法，更诚实的论文定位是先验辅助冷启动的效率及其可靠性边界，而非学习模块不可替代。要采取哪条路线是新的研究选择，本轮不自动启动新架构或新任务搜索。

## 完成情况

全部3240条轨迹预算/唯一性/共同初始化核验通过，16200个选点决策重算通过，648个W/F配对的前40个点和值完全一致。新目标调用1944180次，新增神经训练0轮，原权重和原失败结果不变。结果是同分布新实例的机制检验，不是全新函数族泛化确认。
