# 冻结组件实验：精确方法与身份

本研究候选是条件函数先验辅助的冷启动优化器，不能与原解锁版anchor或旧离线residual选择器混为一谈。沿用fewshot_prior已训练的9个正确模型（3折×3种子）及9个打乱关系模型，持出配方选择相应折。此次不重新选epoch或权重。WA使用固定径向公式，不加载神经网络。

## 搜索流程

1. 在[-5,5]^20均匀采集共同10点，全部计入预算。用这10点的均值和总体标准差（下限1e−6）固定标准化，冻结这10点作为先验上下文，不随搜索更新。
2. 对W、WS、WA，在累计观测数n<40时令alpha=1；n>=40时alpha=0。F始终alpha=1；O、S的模型部分alpha=0。先验输出记m(x)。
3. 在线模型拟合已观测全部点上的目标r_i=(y_i−center)/scale−alpha*m(x_i)。在退出点40重新构建全历史目标，而不是丢掉早期数据。预测为alpha*m(x)+GP残差均值。
4. 使用固定单位幅度Matern5/2核。距离按(x−z)/10缩放，长度sqrt(20)*0.25，对角正则1e−4；不调核参数，全历史精确GP，逐点Cholesky更新。GP方差没有覆盖数据依赖的先验不确定性，不作完整概率校准保证。
5. 每轮生成64个全局均匀候选和64个围绕已付费最佳点的局部高斯候选；局部标准差10*(0.05+0.35*(600−n)/600)，裁剪到搜索边界，排除与历史点距离<=1e−6的候选。候选规则和随机流配对，随状态改变后不能声称候选坐标完全一致。
6. W/O/WS/WA/F按EI（xi=0）选一个候选，P仅按冻结先验均值选最小者。S在共同10点后先付费评估30个Sobol点，再使用同样在线GP和EI。每轮只评估所选点，候选真值不进入排序。
7. 保存全部600点和值、选点前预测、决策分数、GP退出状态、先验身份及目标调用计数。将600次轨迹的前300次作为主要效率观察窗口；不是单独为300预算重新优化过的策略。

P仍读取真实观测来更新最佳点和局部候选中心，且初始上下文也含目标观测。因此P准确称为“冻结先验引导、无在线GP拟合”，不是完全不适应当前任务的静态点序列。

## 指标

主要目标是初始10点最佳值−0.5*样本标准差。达到时间计入初始化；未在300次内达到则记为删失，在受限均值中使用301。达到率另报，不能把301误写成成功时间。

终局效用u=g/(1+g)，其中g=max(初始最佳−最终最佳,0)/初始样本标准差（下限1e−8）。效用差不是百分比。所有组共享初始数据，因此配对目标一致。三个模型种子不等同独立任务；O/WA/S结果共享但只实际运行一次。

## 复核

冻结身份逐项检查源代码、父实验与权重哈希。对所有3240条轨迹检查600次预算、无隐藏诊断调用、点唯一性、共同初始化和先验身份。每条重算5个选点（首轮、退出前、退出后、中期、末轮），使用实际保存的增量目标精度路径，避免重新批量标准化改变训练目标。W/F的648个模型种子配对还须前40点完全一致。

运行秒数包括模型加载和初始化，但24进程并行时的每轨迹时间不是串行部署开销。全部真实评估成本与离线训练成本分开计；此次新增训练成本为0，不能把历史训练说成免费。
