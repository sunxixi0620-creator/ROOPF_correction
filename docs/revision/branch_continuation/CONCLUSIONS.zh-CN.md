# 单次有益提案干预的长期收益诊断

冻结未校准的上下文提案版本New。36个配置、每配置一个新实例、四个独立初始种群、三个固定模型种子。432条原轨迹，各在170/310/520次评估处分支，共1,296条分支。
先完整运行原轨迹，再在独立副本中查询真值。当两个新提案中的最好者优于已有最好值及原拟选两点，保留第一个原选择，用该新提案替换第二个位置；否则不干预。之后恢复原策略。
这是一种借助事后真值的单次干预诊断，不是可部署算法，不是所有可行干预或融合策略的上界。

三个阶段等权汇总：最终收益差-0.000007，95%区间[-0.000028, 0.000011]。
按预先规则，本轮方向判断：`below_practical_threshold_for_single_intervention`。

61次真实机会均取得即时改善，但最终30胜、31负。条件于这些机会，即时平均收益0.006975，最终平均收益−0.000139，最终描述性95%区间[−0.000563,0.000252]。这一条件统计也不支持持久的平均优势；方向胜负不表示损益幅度。

全部预定状态等权汇总的收益从即时0.000328，下降到再评估20次后的0.000170、再评估60次后的0.000055，最终约−0.0000065。最终区间上界约0.0000113，低于预设0.001实质阈值。因此本轮不支持把后续主要投入继续放在识别“即时更优”的当前提案上。

这不证明排序永远无用，也不证明离线在线融合不可能。被检验的是170/310/520三个固定位置、当前提案、一次替换第二评估位置、之后恢复原策略的政策；没有检验初始化后首次决策、持续多次干预、替换两个位置或以信息价值为目标的探索候选。事后即时真值不是终局最优决策的真值。

原有“存在真实改进机会”的诊断仍正确，但这些机会不能直接作为最终互补收益的证据。若继续方法研究，应重新对齐离线提案的训练目标与匹配纯在线策略的剩余预算收益，或明确研究早期加速；不再默认增加epoch、校准排序或恢复旧residual能解决最终优势不足。本轮停止，不自动启动新训练。原论文的双向互补和各组件必要性仍未被完整证明。

优先继续选择机制开发的门槛为汇总最终收益≥0.001、区间下界>0且三个种子均值均为正。条件机会统计不是另一个可替代的验收终点；阶段表不用于事后挑选成功阶段。
区间按12配方簇bootstrap5000次，为当前三个模型上的描述性区间，不能当作新函数族泛化证据。
全部干预前状态/随机数指纹和前缀点/轨迹一致；不干预分支要求全程一致；修改只发生在一个评估位置。
实际计算调用1,036,800次，其中432,000次为分支重复前缀；事后教师5,184次；独立契约检查456次。这些调用不是新的可部署算法测试成绩。
复现：`.venv/bin/python scripts/branch_continuation.py`。源代码、协议、全部状态、动作、标签、原轨迹和分支轨迹均有身份哈希与归档。
