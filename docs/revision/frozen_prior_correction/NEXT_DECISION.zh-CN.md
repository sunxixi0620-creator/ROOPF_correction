# 固定先验在线修正：研究决策

本轮已经完成，联合验收未通过。停止该候选的核参数、40/60划分、训练轮次和旧residual扩展；不启动外部确认。原解锁版权重保持不变。

## 已得到的证据

固定40点条件先验＋全量在线GP误差修正，在20D、600次真实评估下，相对纯先验改善0.019300，相对固定混合改善0.032429；但相对使用全部100点初始化的纯在线GP下降0.004204，相对打乱训练关系的先验下降0.003399，相对径向先验没有可靠优势。四项主比较仅第一项通过。

独立均匀查询的初始预测MSE从纯在线0.663934降到融合0.472805，约降低28.8%。这支持预测迁移价值，不能证明优化价值。融合使用EI相对只用修正均值下降0.005502，说明本配置的EI选择没有兑现终局收益；不能据此断言所有不确定性探索无效。

融合在预定200/300/400/600评估节点都没有超过O100。不能改用有利时刻补救主终点。Mean看似接近O60，也不能事后将其作为新胜出模型。

## 瓶颈与后续边界

证据将问题进一步定位到预测与优化决策之间：平均预测误差改善，并未证明能识别低值尾部的优质候选或值得支付预算的探索。GP只描述修正项的不确定性，没有建模先验误差的全部不确定性；95%区间覆盖率较高也不能证明EI所需的局部概率可靠。这是机制假设，当前实验尚未因果区分尾部排序、方差尺度、候选可达性等原因。

下一项若要开展，应先冻结一个有界的同状态决策审查：复用已保存历史，在共同候选集比较低值尾部排序、真实改进识别、EI与均值分歧的即时收益；若需要新候选真值，单独计入诊断预算，不能流入原轨迹。只有确认可兑现的机会且能由允许的观测识别，才讨论新训练目标或不确定性模型。不直接追加epoch、不扫描融合权重。本轮没有自动启动该新实验。

论文目前可以写在线修正改善冻结先验，以及预测精度和搜索收益可能分离；不能写已证明离线与在线缺一不可、旧residual必要或原三模块已得到验证。本轮是方法重设计的开发证据，仍只有36配置各一实例，不能冒称独立函数族验证。
