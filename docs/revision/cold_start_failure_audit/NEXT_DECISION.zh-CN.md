# 审查后的研究决策

冷启动收益保留；联合验收仍未通过，不变更300次截止点或原目标。

## 失败的具体规模

216个模型种子配对中，W和S共同成功191个，共同失败18个；只有S成功7个，只有W成功0个。7个差异配对只覆盖4个任务实例、3个配方，并非7个独立任务。它们在300次时距离目标仅差0.0068～0.0378个初始样本标准差，全部于324～358次达标。因此可以说差异主要表现为预算内达标延迟，不能说先验导致永久失效；同样不能把预算改成360或600来宣称原主验收通过。

这7个配对中，纯在线O在300次内只成功1个，持续融合F成功3个。它们不仅是相对纯在线的普遍退化，空间填充对这些实例有额外价值的可能性值得保留。但各轨迹不同，不能将此认定为已证实的空间覆盖因果效应或40次退出造成的损害。

## 提前识别证据

仅在当时尚未达标的W轨迹中评价，避免利用已经成功的事实预测成功。20次时有103个风险记录，40次时62个；事件仍只有7个配对、4个实例、3个配方。

低采样展开度与S成功而W失败关联：20次AUC约0.796，40次约0.790。融合相对同历史在线预测的误差增量AUC约0.743/0.758，但区间宽，40次区间包含0.5。低进展对一般W失败有辨别力，却对40次时的S特有优势几乎无辨别力（AUC约0.501）。长停滞在40次时甚至是反向关联（固定方向AUC约0.199）；没有事后反转方向美化结果。

这些是已见任务的探索性关联，16项检查没有多重比较校正；留一配方只检查关联敏感性，不构成新数据泛化。不能从中选出最佳AUC就训练/部署新门控，更不能将S的未来结果当在线特征。

## 下一步建议与停止边界

当前优先项应是冻结现有W/O/S配置，另行预登记更多新实例的复核，以估计冷启动收益及达到率差的稳定性，而不是增加神经训练或微调退出时间。原有任务家族的新实例仍是同分布重复，不冒充未见函数族独立确认；具体规模应在新协议中确定。

只有覆盖率差异重复出现、且可观测空间特征跨实例稳定时，才值得检验一个明确的机制对照：在固定早期预算中加入有限的空间填充采样，测试能否改善覆盖率而保留加速。这一假设是新方法变体，必须另冻协议和新数据，不能按这4个实例调配比例。自适应退出仍没有充分依据。
