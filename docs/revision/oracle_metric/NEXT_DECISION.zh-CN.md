# 受限真实度量诊断后的决策

本轮不启动神经重训，不扫描核长度、结构权重或降维秩。

真实二次度量仅辅助前40次的T40，相对O平均节省3.431次，99%区间[-6.229,13.333]，没有达到至少5次且下界为正的门槛；相对同谱随机方向R40也未通过（3.451，区间[-3.833,12.306]）。相对解析先验WA反而慢16.938次，区间[-24.194,-9.694]。

持续使用真实度量T600相对O只节省0.521次，区间很宽；相对WA慢19.847次，也未通过。于是，当前没有合理证据为“预测真实二次项度量→替换GP距离”这条具体路线投入模型训练。

但这不是完整真实结构上界：二次项并不等于混合目标的整体几何，真实方向也不是当前固定核/候选机制下的最优表示。结论只限定该结构注入方式，不能宣布所有特征学习没有机会。逐配方结果全量报告，不挑出有利配方重新定义总体成功。

研究重点应保持清晰：当前已重复的优势是先验辅助冷启动；神经先验相对简单解析结构没有建立增量优势；已知二次结构的距离注入也未建立足够收益。不能将这些问题统一归因于80轮或1000轮训练不足。

若保留现有任务和方法，论文应保留解析先验强对照，收窄到先验辅助的样本效率与可靠性边界，不宣称离线学习不可替代。若坚持学习作为核心创新，先明确真实相关任务中存在什么可观测的共享信息，再决定学什么；这属于方法/任务定位重设计，需要新协议，不能继续堆同一分布的局部变体。已有共享子空间正对照和此前应用资格审查必须一起参考，避免重复尝试已经没有通过的路线。
