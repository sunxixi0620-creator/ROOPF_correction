# 结构可迁移性与既有证据审查

## 原分布里什么是共享的

依据 `roopf/revision_tasks.py`：12组混合权重配方固定，3种轴谱/频率档位遵循固定规则；变量维数、边界、函数组成形式共享。每个任务以split/fid/instance/dim生成独立随机流，重新采样旋转、平移、频率扰动、相位、势阱中心/深度、shelf方向/阈值、输出尺度/偏移。

因此历史任务不能直接提供某个新实例的同一个旋转方向或同一个最优位置。模型仍可能从源任务学习一般规律，并结合当前观测推断目标结构；本审查没有证明这种条件推断不可能。但10个标量观测不能被默认视为已经识别出20维任务的大量方向/非线性参数，必须另有证据。

旋转矩阵是20×20全维正交矩阵，二次轴谱所有值为正，当前生成器没有显式共享的rank3有效子空间。二次项H=R diag(axis/mean(axis)) R^T；20维全正交旋转本身在各向同性核中不改变距离。因此只让网络输出一个全维旋转，然后沿用各向同性核，会在数学上没有效果。要有效必须改变缩放、维数或采用非线性表示，并承担相应验证责任。

## 之前已经做过什么，不再重复

- `docs/revision/radial_prior_audit/CONCLUSIONS.zh-CN.md`：旧预测器在打乱上下文后退步，相对径向预测有单次选点优势。因此不能把七组闭环的无优势解释成“网络只学了中心”。预测内容与闭环增益不同。
- `docs/revision/shared_structure/CONCLUSIONS.zh-CN.md`：刻意共享rank3方向的受控正对照，闭式学习表示通过matched诊断门槛；并非原36配置生成器中的共享结构，也不是神经网络结果。
- `docs/revision/STRUCTURE_ALIGNMENT_CONCLUSIONS.zh-CN.md`：失配会退化；留一选择缓解失配，但300次终局相对纯在线/径向基线未通过。早期曲线正向，不可追溯替代主终点。
- `docs/revision/cold_start_components/CONCLUSIONS.zh-CN.md`：固定窗口学习先验快于在线和打乱先验，但未超过解析径向先验；在线适应有贡献，学习不可替代性/退出效率必要性未通过。

这些结果共同说明“存在可迁移结构”与“当前任务上结构如何带来增量”必须分别验证。不能再次生成容易的共享子空间任务，把以前已证实的正对照当作新模型解决原问题。

## 本轮上限诊断的严格范围

提供原分布当前实例二次项的真实方向和轴谱，改变GP距离；没有真实平移/最优点、完整非线性特征、候选标签或梯度。此信息在部署中不可直接取得，故仅作诊断。它不是最优表示，也不是全部真实结构的性能上界，不能用失败推论所有表示无效。

变换归一化trace=20以控制平均距离尺度，核参数固定。当前候选池仍在原坐标生成，真实结构仅影响预测距离，不生成特权候选。与匹配随机方向比较控制了轴谱，与解析均值先验比较保留已有强对照。重放只访问已保存标签；复建任务参数不调用目标函数。
