# 真实任务先验试验：结论与后续边界

本轮是首次在本研究支线上用真实分类器训练误差构造相关任务的有界开发试验。任务、数据划分、算法、预算和六项门槛在目标表生成前固定，协议提交为`bb42236`。没有更改原anchor/residual，没有神经网络重训，不是原ROOPF的四组比较。

**结果未建立融合的双向必要性，不能替论文补上这一主张。** F相对固定核纯在线O的归一化遗憾曲线均值改善0.001776，相对在线调核GP-EI改善0.002521，均未达到预设0.005实质门槛。F相对纯离线排序A反而差0.000340，且区间跨零。达到预设质量的截断平均次数，F为2.370，A为2.356，O为2.511；未满足相对两端各节省至少一次评估的要求。计数包括共同初始化，不能将这些均值解释成从第5步开始的收益。

固定先验强度加在线修正的Fixed在本样本的曲线均值最好（0.003915），但这是预设次要对照的描述结果；不按这个结果将Fixed追选为获胜模型，也不重开这批目标任务上的参数搜索。

**任务区分力不足，是这一轮的主要限制。** 85.93%的初始化在4个随机点内已达到目标。追加的事后难度审查（未改变任何算法或终点）发现：平均47.76%的256个配置满足预设质量，37.16%的配置与表内最优并列。先验与目标误差的平均Spearman相关为0.7678。源知识确实具有相关性，但大面积好配置使在线适应的增量价值很难从此试验中识别；不能从这个结果推断所有融合方法都无效。

这是一个1797图像、二参数、有限网格的廉价先导实验，不是昂贵真实任务的完整基准。源/目标不共享图像或类别对，但共享类别和数据采集域；目标类别对之间又共享部分图像，聚类区间只作本数据集开发证据。没有writer身份隔离，也没有独立分类测试误差结论。Bad的错误先验仅是配置索引乱序，不等于真实分布失配或安全性保证。

**停止条件已执行。** 不在这批Digits类别对上改变目标阈值、网格、预算、核参数或选择规则来获得成功，不开展外部成功确认。原解锁版继续保留，residual的必要性仍未解决。

下一轮若继续，应先做与方法排名无关的任务资格审查，再冻结一个新的研究问题：

1. 先落实多数据集或实际应用中有明确来源关系的任务；优先较复杂的多分类/回归调参或真实仿真，而不是继续扩增Digits二分类变体。数据集层面划分源、开发、确认任务；划分、许可证、任务关联依据都需记录。
2. 只用源/开发任务预先核查随机初始化成功率、好配置覆盖率、评价噪声和任务间最优设置差异。资格筛选不能按F是否战胜基线进行，也不能查看确认任务后更换任务或指标。确切准入阈值应在新数据评估前另行登记，本报告不冒充已经完成的预登记。
3. 确认“先验有帮助但单一固定配置不足以解决所有任务”，才值得安排有区分力的纯离线/纯在线/融合比较；否则应将问题定位为配置迁移或暖启动，而非坚持两部分缺一不可。
4. 提前选定任务质量或工程容差以及主要成本指标，配强在线优化器，报告实际训练时间与离线成本。不能再次从终局失败中挑一个有利预算，也不能将当前已看过的数据称为新的确认集。

本轮26,880次真实SVC拟合，离线表15,360次、目标诊断表11,520次；945条轨迹共30,240次表查询。并行24个单线程CPU进程，源表约4.46秒、目标表约3.22秒、搜索表回放约1.78秒；累计单次SVC计时约161.59秒，不将缓存搜索时间当作实际在线训练耗时。原始逐次计时保存在表中，可还原每条轨迹的训练成本。GPU不适用于本libsvm工作负载。
