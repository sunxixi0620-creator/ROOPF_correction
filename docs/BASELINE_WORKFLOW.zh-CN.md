# ROOPF-Agentic 每轮实验与远端基线流程

## 分支与标签

- 原始复现基线：`master`
- 每轮开发分支：`experiment/rNN-<mechanism>`
- 通过验证后的基线分支：`baseline/rNN-<mechanism>`
- 不可变基线标签：`baseline-rNN-<mechanism>`

基线分支用于继续开发和比较，标签用于论文、结果表和代码版本的永久引用。

## 每轮标准流程

1. 从上一轮基线创建新的实验分支。
2. 只实现一个清晰机制，固定训练集、测试集、种子和 NFE。
3. 运行安装检查、冒烟测试和配对早期门控。
4. 保存结果 CSV、运行元数据和必要的消融记录。
5. 若协议正确，即使性能持平或失败，也提交为可追踪的实验轮次。
6. 只有通过预先声明的性能门槛，才标记为“改进基线”。
7. 创建对应的 `baseline/` 分支与 `baseline-` 标签并推送远端。
8. 下一轮必须从该基线或明确指定的更早基线创建，禁止在旧分支上叠加不可追踪改动。

## 推送命令

实验分支提交且工作区干净后运行：

```bash
bash scripts/promote_baseline.sh r01 p4b-controller origin
```

脚本会推送当前实验分支，并创建和推送同名基线分支与不可变标签。

## 结果命名

每轮结果目录使用：

```text
results/rNN_<mechanism>/<benchmark>/<seed-or-batch>/
```

论文表格必须同时记录：提交 SHA、基线标签、真实 NFE、种子、训练/测试函数集合和配置文件哈希。
