## 方法配置

离线顺序为：36 个生成训练函数 → Anchor 预训练及冻结 → 完整候选池日志 → Residual 训练及冻结 → 22 动作配对案例构建。案例共 576 个上下文，464 条用于检索、112 条用于覆盖校准；本项目没有对 LLM 微调。

在线每条轨迹先评价 100 个初始点，随后通常每轮评价 2 点，达到 300 FE 停止；种群保留 100 点，维度 D10。六个生成算子各产生 6 点；保护竞争阶段另有一个竞争 Anchor 和一个额外提议，合计 38 个竞争候选，保护 Anchor 单独保留。

LLM 联合协调生成参数和融合倍率：当前池的融合立即生效 5 轮，温度与指定局部尺度从下一轮起生效 4 轮；活跃阶段 `k=5、15` 决策，分别对应评价前 `FE=220、240`。候选通过保护选择后才进行真实评价，评价结果再更新种群、档案、来源成功记忆和反馈。保护门及评价预算不由 LLM 修改。

## 已完成实验与报告范围

所有条件均为 35 函数、每函数 100 条轨迹、D10、FE300（含初始100）；按 BBOB24、CEC-style6、UAV5 分类报告，不增加跨问题类别的效能合计。Excel 的数值明细按算法/版本排列，仅保留函数、均值和方差。

论文算法对照采用归档均值，不是本轮重新运行的配对结果；当前 Full 与论文原版 ROOPF 同时参排时，Full 的 BBOB24 平均秩为 3.000，排名 1/16；CEC-style 与 ROOPF 并列第一；UAV 排名 6/11。参考排名不代表统计显著性。

三项整模块消融的胜/平/负均从 Full 角度统计，函数按最终均值比较，轨迹按配对终值比较：

| UAV5 | Full vs 移除 Agent | 5/0/0 | 221/136/143 |

重要解释：

- 移除 Anchor 指移除预训练网络及其候选生成路径，以原生信赖域提议补位保护与竞争位置；保留候选数量和其他模块，Anchor 温度控制不再生效。
- 移除在线部分指移除全部六个运行时生成算子及额外原生提议，保留在线代理、Residual、Agent 与冻结案例门；本轮 5800 个决策上下文全部只开放默认动作，Agent 实际改点为 0，这一门控退化影响必须保留。
- 移除 Agent 指移除整套 Agent 框架，其效果不等同于单独的 LLM 推理收益。
- CEC-style 保留结构锁，无 LLM 介入；论文归档的偏移一致性尚未确认。UAV 为恢复的代理协议。
- 最终展示按用户指定将 BBOB20 纳入 BBOB24；其随机符号与跨批求和语义、受控批次及 RNG 仍需披露。冻结实验记录中的单列辅助记录完整保留，未改写。
- 自有实验均值/方差来自每函数 100 条轨迹；论文方差由归档标准差平方得到，保留归档精度，不推断归档未注明的统计口径。
